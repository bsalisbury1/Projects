# Image Classification

## Plan

Thomas wants to gain some practice using PyTorch.  Ben wants to gain some practice with image classification.  The plan will be do image classification on the [Fruits-360 dataset](https://www.kaggle.com/datasets/moltean/fruits) version 2024.08.04.0 from Kaggle where

- Thomas will compare the performance XGBoost versus deep learning models constructed with PyTorch, and

- Ben will compare the performance of LightGBM versus deep learning models constructed with TensorFlow.

Having the different but related architectures in both the gradient boosted tree setting and deep learning setting will allow both authors to explore the differences and similarities between the two models.
